# Casa y Jardín - App móvil

Aplicación móvil en Flutter para las interfaces iniciales de Casa y Jardín.

## Pantallas incluidas

- Inicio de sesión.
- Página inicial del perfil administrador.

La app inicia siempre en la pantalla principal. Por ahora no hay backend ni validación real de usuarios; el botón de ingreso solo permite navegar a la interfaz del administrador para visualizar el flujo.
